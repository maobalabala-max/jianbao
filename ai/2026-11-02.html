AI 前沿情报日报

2026年11月2日 周一阅读约 4 分钟3 条重点 · 1 条信号

今日核心判断

  1. AI 编程工具的扩展市场已成为现实攻击面：Cursor 市场上的篡改版 Claude Code 扩展在线约 11 小时，最多 5000 名用户安装。这次没有酿成大规模入侵，主要是因为恶意代码本身有缺陷，而不是防线拦住了它。
  2. 资本对前沿实验室开始挑剔：据 FT 报道，OpenAI 把本轮融资目标从约 300 亿美元下调到约 200 亿美元；Anthropic 上市后预计只拿到投机级信用评级。融资变贵，会直接压到算力扩张的节奏上。
  3. 周末没有大实验室发布新的前沿模型。中国方面最实质的进展是 DeepSeek 开源了一个主动式 agent 系统原型，Qwen 4、GLM-5.5 的发布时间仍是传闻。

Cursor 扩展市场遭供应链攻击，最多 5000 人中招

  • 10 月 29 日太平洋时间约 2:27 到 13:35，Cursor 扩展市场上架了被篡改的 Claude Code 扩展 2.1.312 与 2.1.313（Windows、macOS），并非 Anthropic 开发。
  • 恶意代码会上报主机名、用户名、公网 IP、Git 邮箱等信息，写入攻击者的 SSH 公钥、安装开机自启，并尝试建立反向 SSH 隧道。开启本机 SSH 服务需要管理员权限，多数机器上这一步失败。
  • Cursor 下架该版本后整体关停并重建了扩展市场，轮换密钥，攻击者服务器已下线。Anthropic 和微软均确认官方渠道（VS Code 市场、npm 包）未受影响；扩展如何被传进 Cursor 市场仍未说明。
为什么重要

开发者机器上的 agent 扩展权限很大，第三方镜像市场成了比官方渠道更薄弱的一环。【分析】

疑点

攻击者如何取得上架权限尚无说明。

看点

Cursor 是否公布入侵路径和事后复盘。

OpenAI 下调融资目标，AI 融资环境转紧

  • 据 FT 10 月 30 日报道、CNBC 次日证实，OpenAI 本轮融资目标从约 300 亿美元降到约 200 亿美元，投后估值目标 1.25 万亿美元，首轮交割预计不足 200 亿美元；阿联酋财团（含 MGX）预计领投。据 TechCrunch 转述 WSJ，目前已落实约 110 亿美元。
  • 据 FT 报道，黑石告诉投资者，Anthropic 上市后预计获得 BB 档（投机级）信用评级，主要因为巨额算力承诺和持续亏损。
  • 据 The Information 与彭博报道，英伟达正洽谈为 Nscale 的西弗吉尼亚数据中心提供数十亿美元信用担保；Nscale 文件显示，Anthropic 已为首栋 460 兆瓦设施签下最高 446 亿美元合同。
为什么重要

两家头部实验室都在为上市前的资金结构承压，芯片商为客户的数据中心作担保，风险正往供应链上游集中。【分析】

看点

OpenAI 首轮交割的实际金额。

重点 · 3官方/一手媒体报道

DeepSeek 开源主动式 agent 系统原型

  • DeepSeek Harness 团队 10 月 31 日晚发文介绍 Super-agent 设计：双层架构、事件驱动、异步多信道交互、存算分离和外部看门进程，目标是让 agent 同时处理多任务和团队协作，不再受限于人的注意力。
  • 同时以 MIT 许可在 GitHub 放出 dsh-superagent-prototype：监听一个代码仓库的 GitHub 事件（可选飞书），为每个问题建工单和隔离的工作会话，通常以 PR 回复。官方说明仅供研究，工作会话会不经审批执行命令。
  • DeepSeek 称内部实例已在持续运行，参与问题复现、修复和代码审查。
为什么重要

中国实验室开始公开「AI 参与自身工具迭代」的系统设计，并给出可运行代码。【分析】
