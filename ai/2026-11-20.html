台积电、三星暂停部分对华先进芯片订单

  • 英国《金融时报》11 月 19 日首报，台积电和三星在申请美国商务部许可期间，暂停对部分中国客户出货。
  • 路透援引两名知情人士称，台积电要求受影响客户 16 纳米及以下的订单在取得美国出口许可前一律暂停；这些客户一般只能用 28、40 纳米工艺，且芯片不得使用高带宽内存或先进封装。
  • 起因是美国商务部周四生效的新规：台积电不能再靠自查算力等参数判定中国设计是否在管制之外，受影响客户的先进芯片默认需要许可。台积电还要审查客户的股东、封装商和运输路线，海外子公司下单也算在内。
为什么重要

这条路一堵，中国 GPU 替代方案要么依赖国内产能，要么停在老工艺上。【分析】

疑点

《金融时报》原文付费，三星部分依据二手转述；台积电、三星均未公开表态。

来源路透 · 英国《金融时报》

欧盟委员会确认遭 AI 工具发起的网络攻击

  • 欧盟委员会发言人 11 月 19 日在例行发布会上确认，10 月 22 日发现入侵，26 日确认，称这是一场“AI 生成的网络攻击”，用的是公开可得的 AI 工具；目前未发现员工数据大面积泄露，也没有收到勒索要求。
  • 据 Politico，人事、薪资、医疗报销和翻译系统停摆超过 10 天；CERT-EU 识别出攻击者使用 ARTEX。
  • CERT-EU 11 月 5 日发文：ARTEX 是开源、由大模型驱动的自动渗透测试平台，接外部商用模型，可自主完成侦察和漏洞利用；原作者 10 月已下架仓库，但多个分叉仍在流传。
为什么重要

开源 agent 框架加商用模型，就能大规模地自动攻击，防守方只能同样提速。【分析】

疑点

入侵途径和攻击者身份都没有公开。

来源欧盟委员会 · CERT-EU · The Record

微软 agent-framework PyPI 包被植入窃密代码

  • GitHub 安全公告和 PyPI 公告显示，11 月 17 日（UTC）有人未经授权发布 1.26.1、1.26.2 两个版本，借 .pth 启动钩子在每次启动 Python 时窃取环境变量、云凭据、Azure DevOps 和 GitHub Actions 的令牌；两版已在一小时内下架，1.26.0 未受影响。
  • 安全公司 Wiz 称，攻击者疑似窃取了微软发布签名流水线的证书，使用的工具自称是开源 AI 渗透框架 Cairn。
为什么重要

agent 开发框架本身成了供应链攻击目标，CI 里的令牌是攻击者最想要的。【分析】

来源GitHub · OSV · Wiz

谷歌：Gemini 能操作 Mac，并公开 agent 测试用的“镜像网络”

  • Mac 版 Gemini 应用上线电脑操作功能：在隔离的后台窗口里跨本地文件、桌面应用和网页完成多步任务，用户选择允许访问的应用，关键操作需确认；先在美国开放英文版，限 AI Plus、Pro、Ultra 订阅和 Apple 芯片 Mac。
  • Chrome 安全团队同日介绍“镜像网络”：在 gVisor 沙箱里搭建数千个仿真网站，agent 访问真实网址却被导向生成页面，用来测试自动浏览功能对提示词注入的抵抗力；站点由多 agent 系统自动搭建。
为什么重要

为避免模型察觉自己在被测试，评测环境要做得和真实网络难以区分，这正成为 agent 安全测试的通行做法。【分析】

疑点

谷歌未说明 Mac 版功能是否经过同一套测试。

来源谷歌 · 谷歌安全博客

重点 · 5官方/一手

OpenAI 用 Codex 自动排查 ChatGPT 性能问题

  • OpenAI 介绍内部系统 Performance Factory：性能告警触发后，Codex agent 自动调查、提出修复，工程师审核上线后再由 agent 核对是否恢复到基线。
  • 三个多月里，该流程跟踪了 1,700 多次调查，查明 600 多个根因；目前的瓶颈是等工程师审核合并，OpenAI 称正在探索让 agent 自己完成这一步。
为什么重要

与昨天的研究加速报告一致，agent 在可重复的工程环节先落地，人工审核仍是最后一关。【分析】

来源OpenAI
