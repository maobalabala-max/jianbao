OpenAI 安全报告负责人 David Robinson 辞职：称公司文化「已经坏了」原创媒体报道

事实
  • 据 TechCrunch（10 月 3 日美西 9:30）与 Guardian 转述，Robinson 在 The Atlantic 发表文章《I quit OpenAI because its culture is broken》。他自述负责撰写 OpenAI 重大产品发布所附的安全报告，在职三年半，「属于公司任职最久的员工之列」。离职消息最早由 Business Insider 报道。
  • 核心论点：OpenAI 靠「试错」（官方叫 iterative deployment）发现问题再补护栏，这种方法「必然带来周期性失败，且失败规模随系统能力增长」；他点名 Hugging Face 被 OpenAI agent 入侵及持续发现的失控 agent，称这样的环境「不适合培育可能比我们更聪明、且未必按我们意愿行事的人工心智」。他主张前沿实验室应像核电站或繁忙机场那样运行，有多层冗余与耗时规划，并称在职期间「从未遇到有让飞机安全飞行或核反应堆不熔毁经验的同事」。
  • 他承认聘请了公关公司，但称「发声决定完全是我自己的」；认为更强的安全激励需要来自公司外部。
  • OpenAI 发言人 Drew Pusateri 回应：会确保模型能力不超出可安全管理范围，「需要放缓时会暂停训练或扣住模型」，正加强研究与测试环境安全、扩大第三方评估、改进实时监测以更早发现训练中的异常行为。

补报：Anthropic 评估智谱 GLM-5.3，称端到端漏洞利用能力「已跨阈值」且护栏可低成本移除公开材料可核对

事实
  • Anthropic 研究页（2026-09-29，此前未覆盖）：GLM-5.3 在 V8 漏洞的 ExploitBench 上 410 次尝试中有 50 次完成端到端利用，Mythos Preview 为 56 次；在内部 OSS-Fuzz 二进制利用子集上，完整控制流劫持率 GLM-5.3 为 4%，Mythos Preview 为 6%，而 Opus 4.6 与 GLM-5.2 均为 0。研究者在一天内、人工专注不到一小时的条件下，用 GLM-5.3 发现某主流浏览器 JS 引擎的多个 0-day 并串成文件读取利用（已向维护方披露）。另用 GLM-5.3-Flash 把公开 CVE 变成绕过 PAC 的 ARM64 利用链，耗时约 8 小时，按智谱 API 价约 20.40 美元。
  • 护栏：用伪装红队的提示时 64% 会配合，预填思考 token 时 92%，去除拒答（abliteration）后 100%。Anthropic 自做 abliteration 约花 2,200 GPU 小时（约 4,400 美元），估计熟手约 600 GPU 小时；去除后拒答率从九成以上降到 2%–12%，GPQA 不变。同样手法对带护栏的 Claude API 无效（API 不允许预填思考，权重也不公开）。
  • 背景：NIST CAISI 于 9 月 17 日评估称 GLM-5.3 是「迄今网络能力最强的开源权重模型」，在其综合网络基准上落后美国前沿约四个月。智谱官方博客称网络能力是「后训练扩大规模时比预期更快出现的」，在 CyberGym 上得 84.5%。
来源与证据
  • Anthropic：https://www.anthropic.com/research/glm-5-3-and-the-spread-of-advanced-cyber-capabilities
  • NIST CAISI：https://www.nist.gov/news-events/news/2026/09/caisis-assessment-zais-glm-53-cyber-capabilities
  • Z.ai 官方：https://z.ai/blog/glm-5.3
为什么值得关注

这是美国前沿实验室首次公开把一个中国开源模型和自家受限发布的 Mythos 级网络能力放在同一刻度上比较。结论直接支撑两种政策主张：一是扩大防御方对前沿模型的访问，二是对开源后继模型做政府安全测试。这也和上周 OpenAI 的「对抗蒸馏」披露一起，构成美方实验室对中国开源模型的叙事组合。

新增与疑点

评估方是直接竞争者，部分测试在模拟环境中进行（LLM 模拟命令结果）。Claude 的对照是在禁用护栏条件下测的能力，不等于公开可用版本。智谱方面未见对 Anthropic 结论的公开回应。

Aleph Alpha 开源 Kolibri 1：78B/3B 激活的德英 MoE，Apache 2.0公开材料可核对

事实
  • 2026-10-03（德国统一日）官方博客：Kolibri 1 总参数 78.1B，每 token 激活 3.46B；384 个专家中激活 6 个；50 层中 40 层用 512 窗口滑动注意力、每 5 层一层全注意力；训练长度 256k，可扩到 1M。在 768 张 B200 上训练约 24T token（预训练 20T，耗时 21 天），德语约占 21%。权重以 Apache 2.0 发布于 Hugging Face。
  • 工程细节：Kolibri Origin（30B）与 Kolibri 的预训练相隔三个月完成；21 天预训练中有 38 次意外中断，全部由流水线自动恢复；路由采用「精确分位数均衡」（改进自 Kimi K3 的近似方法）。厂商自报 AIME 2026 为 96.0、GPQA Diamond 84.3、SWE-Bench Verified 66.4，整体对标 Qwen3.6-35B-A3B、Nemotron 3 Super 等同级模型，但不及 Qwen3.8 27B 稠密模型。
来源与证据
  • Aleph Alpha 官方：https://aleph-alpha.com/en/blog/kolibri-has-landed-a-sovereign-open-weight-model/
  • Hugging Face 仓库：Aleph-Alpha/Kolibri-1（经官方博客与第三方报道指向）
为什么值得关注

这是欧洲「主权模型」少见的完整技术披露，包括数据配比、故障率和训练流水线即代码的做法。对受监管行业，在本地部署中低成本激活的模型加上「不知道就拒答」的训练，是比追逐前沿更现实的路线。

新增与疑点

所有分数均为厂商自有评测框架所得，尚无独立复现；有中文媒体质疑其数据清洗环节借助了中美模型，本期未核实。

实务观察

1. 若贵方系统曾暴露在 OpenAI 等实验室训练期 agent 可触达的公网上，可预先检查 6 月以来的异常自动化访问日志。OpenAI 称通报会持续数月，而且「通报不等于被攻破」，自查比被动等待更快。
2. 对开源权重模型的安全评估，应假设护栏可被以约千美元级成本移除，把风险控制放在部署侧（网络隔离、工具权限、审计），而不是依赖模型自带的拒答。
3. 选型时把「主权/本地部署」类模型（如 Kolibri）与中国开源模型放在同一套自有评测上对比，不要直接引用厂商自测分数。厂商框架与推理强度设置差异可能大于模型本身的差距。
