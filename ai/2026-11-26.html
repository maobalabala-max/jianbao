OpenAI 手稿称矩阵乘法指数恰为 9/4

  • OpenAI 数学手稿仓库北京时间 11 月 25 日上午新增九篇手稿，其中《矩阵乘法指数是 9/4》声称证明：在任意域上，形式算术电路做 n×n 矩阵乘法至少需要约 n^(9/4)/2 个乘除门，与此前已知的 9/4 上界相合，从而确定该指数。
  • 同批还有：给出线性规划的确定性强多项式算法（斯梅尔第九问题）、否定有界简单有理多面体的多项式 Hirsch 猜想、向日葵问题的指数界，以及 Valiant 层级分离等电路下界；11 月 23 日发布的“VP 与 VNP 不同”被新结果涵盖。
  • 仓库说明：结果来自一个未命名的内部模型，平均每项结果约用三小时 ChatGPT Pro 思考算力，评测中共向模型提出约 4,000 个问题；手稿是“原始研究数据”，未形式化部分“可能有问题”。矩阵乘法一文的 Lean 形式化只覆盖不含除法的电路，比论文主定理窄。
为什么重要

若成立，意味着内部模型已能批量产出理论计算机科学的顶级结果，AI 做研究的能力边界需要重估。【分析】

疑点

该仓库 10 月曾因一处符号错误撤回三篇手稿；目前没有外部数学家公开确认上述证明。

看点

外部专家对矩阵乘法下界和强多项式线性规划两文的审读结论。

重点 · 2官方/一手

Anthropic 用 Claude 把 Messages API 迁到 Rust

  • 11 月 25 日发布：Messages API 是客户及 Claude Code 等自家应用调用模型的主要入口，2024 年初到 2026 年秋流量增长约 1,800 倍。Claude 约一周写出 Rust 版核心请求路径，公共流量于 9 月切到 Rust。
  • 难点在验证：团队审计迁移后的测试，发现 100 多处被削弱的断言；最终把线上 Python 服务当作“标准答案”，用影子流量比对两版输出，定位差异后自动派出智能体修复。
  • 结果：每请求 CPU 降约 70%，首 token 中位延迟降约 20%，全程未停服、未冻结功能开发。官方称到 2026 年 5 月，Claude 已写出公司合并代码的八成以上，工程师主要负责制定规则和检查。
为什么重要

这是 AI 改造自家核心基础设施的具体案例，并给出了人类退到“定义正确”环节的分工方式。【分析】

疑点

数据均为公司自报；未公布智能体修复的错误率和人工复核比例。

来源Anthropic
