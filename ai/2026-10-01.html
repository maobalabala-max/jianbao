重点消息

Google 发布 Gemini 4 Argon：多榜自称领先，首发仅 Fairwind「可信网络防御方」【公开材料可核对】独立交叉确认

事实
  • 2026-09-30，Google DeepMind SVP / Chief AI Architect Koray Kavukcuoglu 发文宣布 Gemini 4 Argon：面向复杂长程工作流；首批经 Fairwind Program 向一组 trusted cyber defenders 滚动；公司称正参与美国政府自愿预发布模型访问流程，并在加固护栏后「尽快」向开发者、企业与消费者放开，起点为付费 API 与 Google AI Ultra。
  • 能力与内部用例（官方口径）：DeepSWE v1.1 77.9%（高于 Claude Opus 5.5 74.2%、GPT-6 Astra 74.1%）；AutomationBench 51.3% 第一；LVBench 91.7%；CWE-bench v1 与 Astra 并列 68%；Vals 系列与 Harvey Legal Agent 等知识工作评测自称领先。输出 token 上限由先前约 64K 提至 100 万。内部：量子算法子程序时空资源优化自称数分钟内相对发表基线提升约 40%；Argon agents 分析机群 profiling 以释放逾 300 TiB 内存（总潜在节省口径 500 TiB–1 PiB）；大规模 C/C++→Rust（含 Fuchsia Zircon 等，强调强审计）；libgav1 示例称替换约 32K 行 SIMD 后较既有 Rust 移植快 2.7× 且输出一致。对可信防御方与 Google 内部将提供无 cyber guardrails 的防御向能力；Wiz Scan for Good 称用其发现医院软件中其他前沿模型未检出的敏感信息暴露。
  • 价格（公布、尚未对公众默认可用）：首发介绍价输入 $2 / 输出 $10 / 百万 token，缓存输入约 95% 折扣；介绍期结束后 $4 / $20。护栏重点：滥用（含 cyber/CBRN）、间接提示注入（Gray Swan IPI 自称领先）、思维链/动作错位监控（监控结果刻意不回灌训练以免学会躲避）、高风险训练前沙箱隔离硬化。
  • VentureBeat 对官方对比表的梳理：18 项中 Argon 独首约 12、并列 1；Astra 在 FrontierSWE v2、Terminal-Bench Science 等仍大幅领先；Opus 5.5 在 Terminal-bench 4.0、PostTrainBench 等占优——「广度领先」而非全面碾压。

为什么值得关注

DevDay 次日，Google 用「防御向首发 + 政府预发布流程」把 Gemini 4 从「年底前」预期落到可核验公告；定价若兑现，介绍期与 GPT-6.1 Sol / Claude Sonnet 5.5 同档、低于 Astra/Opus 标价，会直接改变中档默认路由竞争。内部 agent 迁库/省内存案例，是「模型参与自家工程」的可引用材料，但仍属单方叙述。

新增与疑点

介绍期时长未写死；多数分数为 Google 自报，需第三方复现与污染检查。无 cyber guardrails 的防御通道与「滥用拒答」产品通道如何隔离，是上线后的关键运维问题。Kavukcuoglu 上周「远早于年底」口径本日落地为有限放行，不等于公开 API 已通。

FTC 确认调查 Anthropic、OpenAI 等；白宫前一日签署「道德约束」自愿协议【原创媒体报道】独立交叉确认

事实
  • 2026-09-30，Reuters/CBS 等：FTC 确认对 Anthropic、OpenAI 及其他前沿实验室就技术对消费者的潜在风险开展行业级调查；拟发正式信息要求，并起草民事调查请求（CID）迫使高管作证；调查对象含曾为两家做独立安全事件核查的研究机构 METR。发言人称关注是否违反 FTC Act（不公平/欺骗性做法等）；主席 Ferguson 在 Hugging Face 事件前已有担忧，事件后紧迫性上升。New York Post 为首家爆料媒体之一。
  • 2026-09-29（美东，报道时间戳进入本窗口）：特朗普与 Brockman、Pichai、Amodei、Huang、Zuckerberg、Musk 等签署自愿「超级智能」原则声明（总统称「几乎像宪法」「道德上有约束力」）；承诺四层管控与审计（内部评估、外部审计、董事会审查等）并定期会合；文本称未来「或许」立法成文化。同日行政令推动联邦用语改称「Super Intelligence」。无法律强制力。

为什么值得关注

自愿协议与 FTC 调查同窗口出现，构成「自我监管政治表演 vs 现有消费者保护法执法」的对照。METR 被点名，意味着第三方评测机构也可能进入取证范围。对企业侧：评测沙箱、越权披露时效、对消费者陈述的准确性，可能比口号式安全承诺更先变成合规文件。

新增与疑点

调查具体争议焦点（安全声称、事故披露、代理行为责任等）尚未公开；CID 文本未见。白宫协议一页原则，操作性弱于各公司既有 RSP/Preparedness。Investing.com 等转述 WSJ：Roosevelt Room 内 Huang 等质询 Amodei 的风险公开口径——正文付费，本日仅作背景，不升格为独立核验事实。

DeepSeek 开源昇腾版训练基建六件套（对位既有 NVIDIA 组件）公开材料可核对

新增与疑点

「接近硬件上限」为官方/转述口径；跨集群真实训练复现、驱动/CANN 版本锁定与许可条款需自行验证。不等于 DeepSeek 已宣布全面弃用 NVIDIA。

早期信号

OpenAI CRO Mark Chen：训练全程监控；约 5%–10% 算力转向安全监测原创媒体报道

事实

实务观察

1. Argon 公开 API 前先定评测矩阵：对齐 DeepSWE / 终端与计算机使用 / 法务金融长程任务 / 提示注入，预留与 GPT-6.1 Sol、Claude Sonnet·Opus 5.5 的同价位对照；在 Fairwind 未覆盖的团队，勿把媒体榜首当作已可采购的默认路由。
2. 代理评测与对外安全声称进入「可被取证」阶段：FTC 调查窗口下，沙箱隔离、出网策略、事故发现到披露的时效、第三方（含 METR 类）报告留存，比再发一版原则声明更紧迫。
3. 昇腾路线选型看「算子+通信」闭环而非单仓库 star 数：若业务绑定华为 NPU，可跟踪 TileLang/DeepEP-Ascend 在真实 MoE 训练中的稳定性与版本钉扎；仍保留 CUDA 对照基线。
