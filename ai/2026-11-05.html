重点 · 1官方/一手

OpenAI：未发布模型自动挖出 948 个 Linux 提权漏洞

  • OpenAI 11 月 4 日发文：用「即将推出的网络安全模型」搭建发现、复现、评估可利用性、生成补丁的多 agent 流程，10 月中旬对最新 Linux 内核跑了一轮。2308 个候选问题中复现 1724 个，最终得到 948 个不同的本地提权漏洞（普通用户可拿到 root），全程 API 费用约 121 万美元。
  • 7 月用 GPT-5.6 Sol 跑同样流程只找到 166 个；新模型在内核又经三个月加固后仍多出 5 倍以上。OpenAI 称 agent 用了至少 10 种此前未知的利用技术，细节出于安全考虑不公开。
  • 早期一轮中，有 20 个「成功」利用实际是借了另一个未知漏洞拿到 root，之后加了独立校验。OpenAI 已向维护者提交数百份报告和补丁，最后一步仍由人工审核。
为什么重要

按 OpenAI 的说法，未及时打补丁的系统上，一个低权限账号对资源充足的攻击者已基本等于 root 权限。【分析】

疑点

所用模型名称、发布时间都未公开；补丁质量尚无维护者的独立评价。

看点

该网络安全模型何时发布、向谁开放。

重点 · 2官方/一手

月之暗面开放 Kimi K3.1 Pro 完整权重

  • 11 月 4 日，Kimi K3.1 Pro 权重上线 Hugging Face：MoE 架构，总参数 2.8 万亿、每个 token 激活 1040 亿，100 万 token 上下文，支持图像输入，训练时即按 MXFP4 量化，文件约 1.56TB。
  • 许可证基本允许商用，但 API 转售年收入超 2000 万美元需另签协议，超大产品须标明模型名。
  • 月之暗面称开源版去掉了网络安全相关训练数据，内部漏洞利用测试得分从 90.5% 降到 81.0%。模型卡上的对比成绩多为自测，评测框架不统一。
为什么重要

这是目前可下载的最大模型之一，自测终端编程成绩接近 Claude Opus 5.5；第三方托管后推理价格可能下降。【分析】

来源Hugging Face · Neural Brew

腾讯发布混元 Hy4，首次支持视觉与电脑操作

  • 腾讯 11 月 4 日发布 Hy4 正式版，财新称参数规模为 770B（Hy3 不到 300B）。新增视觉理解和电脑操作能力，针对 Blender、CAD 等专业软件做了专项训练；权重和系统卡将于近期公开。
  • 据路透，腾讯称网络安全训练数据只保留防御用途，排除了编写攻击工具、入侵系统等内容，内部测试未见更高攻击风险。
  • API 价格与 Hy4 预览版相同，每百万输入 token 约 0.9 美元、输出约 2.7 美元。腾讯自己承认与顶尖闭源模型仍有较大差距。
看点

权重与系统卡的实际公开时间。
