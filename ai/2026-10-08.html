重点 · 1官方/一手

OpenAI 公开 722 篇数学稿件，出自未命名的内部前沿模型，形式化验证只覆盖一部分

  • OpenAI 10 月 6 日（美国时间）在 GitHub 公开 openai/math 仓库：722 篇稿件，归为 372 个结果族，覆盖多个数学分支，另附证明材料、部分结果的 Lean 形式化证明，以及 10 份删节版推理摘要。仓库说明称，原有数学评测饱和后，团队把评测扩展到开放研究问题；评测期间共向模型提出约 4,000 个问题，每个结果平均耗费约相当于 3 小时 ChatGPT Pro 思考的算力。
  • README 明确写道：并非所有稿件都有形式化证明，「部分未形式化的结果可能有问题」。本期自行统计，截至 10 月 8 日早，仓库形式化目录（lean/formalization.yaml）列出 192 篇主结果已形式化的稿件，约占四分之一；10 月 7 日第三方统计时为 162 篇，说明仓库仍在补充。
  • 模型未命名、未发布。OpenAI 称已咨询普林斯顿高等研究院（IAS）的「数学与 AI 独立顾问组」。New Scientist 指出，这次发布与该顾问组的若干建议不符：顾问组建议公开模型名称、提示词与算力成本，尽量形式化，并披露尝试失败的问题数量和选题方式。OpenAI 回应称在探索符合指引的社区托管方案，并会改进论文的引用与表述。
  • Scientific American 报道，OpenAI 称几乎所有结果都来自交给单个 agent 的同一条提示词，部分结果经过多次尝试。
  • 数学家反应：UCL 的 Francis Johnson 研究 Wall D(2) 问题 25 年，该问题在这批结果中，他说自己「已经放弃了」，对 AI 这么快做到感到意外；帝国理工的 Kevin Buzzard 说其中与数论相关的 30 篇里只有 7 篇看起来有分量，只有 1 篇经 Lean 验证，其余要等专家逐篇审读或补上形式化。
为什么重要

这是「AI 参与研究」迄今规模最大的一次单批输出，也直接说明 OpenAI 内部还有比已发布模型更强、尚未命名的模型。产出速度已经超过数学界的审稿能力：arXiv 自 10 月 1 日起对每位提交者设每月两篇的上限，OpenAI 这批稿件则放在了 GitHub 上。

疑点

Lean 证明只能说明形式命题被证明，不能说明形式命题与论文表述一致，也不能说明结果新颖或重要。社交媒体上「证明了准黎曼猜想、触及千禧年难题」之类说法并不来自 OpenAI 自己的材料，本期未能核实，不予采信。

来源GitHub 仓库 · OpenAI 开发者社区公告 · New Scientist · Scientific American · 华盛顿邮报

重点 · 2官方/一手

Anthropic 发布 Claude Haiku 5.5：小于 10 万 token 的请求比 Haiku 4.5 便宜 90%，Sonnet 5.5 缓存读取降价一半

  • 10 月 7 日发布，模型 ID 为 claude-haiku-5-5，已上线 Claude Platform、AWS、Google Cloud、Azure 和 Claude Code。这是第一款支持可调 effort 的 Haiku。
  • 分档定价（每百万 token）：10 万 token 以内输入 $0.10、输出 $0.50、缓存读取 $0.01；超过 10 万 token 时分别为 $0.50、$2.50、$0.05。Haiku 4.5 为 $1/$5。官方按实际用量估算平均便宜约 75%，并说明新分词器每个任务会多用一些 token。
  • 厂商自报分数（对比 Haiku 4.5）：OSWorld 2.1 离线子集 72.4%（15.7%）、HLE 无工具 45.9%（10.2%）、Terminal-Bench 4.0 39.2%（0.0%）。官方也承认复杂 agent 编程仍应用 Sonnet 5.5（Terminal-Bench 4.0 为 70.6%）或 Opus 5.5，Haiku 定位是压缩、摘要、子 agent 和浏览器操作。
  • 同步调整：Sonnet 5.5 缓存读取从每百万 $0.20 降到 $0.10，官方称多数 agent 任务因此便宜约 20%；Max 5x、Max 20x、Team 订阅本周起每月分别附送 $100、$200、最多 $500 的 API 额度；Python/TypeScript SDK 加入 computer use 与 browser use（beta）。
  • 安全：网络安全防护比 Haiku 4.5 更严，但比其他新模型宽松，仍拦截渗透测试类请求；生物防护与 Sonnet 5.5 一致。
为什么重要

Haiku 5.5 在 10 万 token 以内与 GPT-6 Luna 同价，旗舰级实验室的小模型价格已经压到接近开源模型的托管价。它与 Max/Team 附送 API 额度一起，看起来是 IPO 前把订阅用户导向 API 生态的动作。

来源Anthropic · AWS

重点 · 3媒体报道

The Information：微软、Meta 压缩员工内部 Claude 用量

  • The Information 10 月 6 日报道（本期只读到二手转述）：微软年初预计内部 Claude 支出至少 10 亿美元，后来削减了三分之一以上，做法包括减少 Claude Code 订阅、让员工通过 GitHub Copilot 调用模型（自动模式多数请求走 OpenAI 模型）。Cloud & AI 部门多数员工的月度 AI 用量上限从 10 万美元降到约 1 万美元。
  • 微软发言人确认，内部默认 AI 编程模型已改为 OpenAI，工程师仍可选用 Claude。
  • Meta 的 Claude Code 用户从年初约 6 万降到约 3 万，自研的 Metacode 用户超过 3 万、Muse Code 约 6,000；过去 28 天在 Claude Code 上仍花了 1.05 亿美元以上。
  • 两家仍是 Anthropic 的大客户：微软每年至少支付 20 亿美元，用于面向客户的 Copilot 功能，报道称其对 Anthropic 的总支付与年初峰值相近。
为什么重要

这是头部 AI 编程工具在大公司内部用量见顶、并被自研模型替代的少见数据，可与 Haiku 5.5 降价和 API 额度放在一起看。数字来自匿名信源和内部材料，只有「默认模型改为 OpenAI」一点得到公司确认。

重点 · 4官方/一手

GPT-6 进入 ChatGPT，Intelligent UI 让回答直接带图表、表单和小工具

  • OpenAI 10 月 7 日起向 Plus、Pro、Business、Enterprise 推送 GPT-6（由 GPT-6 Sol 驱动），菜单里取代原「Latest」。The Verge 称 Free 和 Go 用户 10 月 8 日开始获得 GPT-6 Luna；帮助中心页面写的却是 Free/Go 使用 GPT-5.6 Luna，两处说法不一致，以实际推送为准。Pro 档位仍是 GPT-6 Astra，不支持 Intelligent UI；Work 与 Codex 的模型不变。
  • Intelligent UI：模型自行决定何时用图示、图表、可点按钮、表单或内嵌小工具（如计算器、分账工具）来回答；回答可在模型仍在思考时先出一部分。OpenAI 设计团队的 Ian Bach 在 X 上称这用的是自家的生成式 UI 语法，不是直接输出 HTML。网页版可在设置中关闭「Layout and visuals」，但不能完全退回纯文本。
  • 同期开发者侧：Decisions API 公开测试（仅 gpt-6-luna，返回是非、选择或打分等结构化判断）；API 付费档位简化为 Build、Launch、Grow 三档。
为什么重要

GPT-6 首次覆盖 ChatGPT 每周约 12 亿用户，产品重点从「更聪明」转向「回答的形态」。不少用户追问为何上线的是 GPT-6 Sol 而不是已在 Codex 中提供的 GPT-6.1 Sol，OpenAI 未解释。

来源OpenAI · OpenAI 帮助中心 · The Verge · Decisions API 公告

重点 · 5官方/一手

Mistral Large 4 公开预览：1.05T 总参数、约 52B 激活，权重本月底放出

  • 10 月 6 日发布，通过 Mistral Studio API 预览。官方博客写的是 1T 参数、每 token 激活 49B；文档和 Hugging Face 写的是含嵌入与输出层共 52B 激活、总参数 1.05T，视觉编码器 1.6B，上下文 1M。
  • 预览价每百万 token 输入 $0.68、输出 $2.09（原价的五折）。Hugging Face 页面显示权重预计 10 月 31 日放出。
  • 放权重之前，Mistral 正与网络安全机构、经审核的合作方和国家机构在真实环境中做红队测试，这些机构使用的版本审核更宽松、网络能力更强。SiliconANGLE 报道，训练没有在当前版本停下，后续会推出更大更强的版本。这是 Mistral 30 亿欧元 D 轮融资后的第一个里程碑。
为什么重要

「先给安全机构用、再放权重」的发布节奏，Mistral 和 Reflection 都在采用，开源权重实验室正在形成先做红队再开放的惯例。架构和后训练细节要等权重发布时一起公开。

来源Mistral · Mistral 文档 · Hugging Face · SiliconANGLE

澳议会听证：OpenAI 的 Kwon 当面道歉，承认通报迟缓；Anthropic 称正敲定让澳 AI 安全研究所独立测试模型

  • 据 ABC、Guardian、Bloomberg，10 月 6 日悉尼听证上，OpenAI 首席战略官 Jason Kwon 就训练期 agent 访问澳 Medicare 统计系统一事道歉，承认应更早通知澳政府，不该等查清更多事实再说；他还称，9 月 1 日 Sam Altman 会见副总理 Marles 时并不知情，而公司员工几周前就已发现此事。
  • Kwon 称 OpenAI 现在会在模型训练中以不当方式联网时向员工告警；NSW 公园与野生动物服务的事件上周发现后很快就向州政府报告了。他在澳期间会面试「工作组」人选。

为什么重要

这是上期早期信号的后续。OpenAI 首次公开承认内部上报链条失灵，以及训练期联网告警是事后才补上的。两家实验室都表态支持强制事件报告，这在主要司法辖区里尚属首次，可能被其他国家援引。

实务观察

  1. 重新评估小模型路由。Haiku 5.5 和 GPT-6 Luna 在 10 万 token 以内的价格已降到 $0.10/$0.50，但 Haiku 超过 10 万 token 后单价涨 5 倍，新分词器还会多用 token。建议用自己的真实请求长度分布，算一遍单任务成本再决定是否切换。
  2. 引用 AI 生成的数学结果时，把「有 Lean 形式化」和「无形式化」分开对待：前者也要核对形式命题是否与论文表述一致，后者在专家审读前只能当作线索。
  3. 内容来源核验不能只依赖单一水印检测器。SynthID Detector 只认 Google 及合作方的水印，textGrain 在轻度改写后检出率明显下降。「未检出」不等于人工创作，需要合规留痕的场景应另做来源记录。
