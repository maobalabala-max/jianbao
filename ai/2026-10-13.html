重点 · 1官方/一手独立交叉确认

Meta 发布 Muse Wonder 前沿模型

  • 10 月 12 日 Meta 发布 Muse Wonder 与 Muse Wonder Full，称在个人/专业 agent、记忆与编程上达到前沿水平；内部代号曾为 Watermelon。在 Prometheus 吉瓦级数据中心训练。
  • Wonder 经 Meta Model API 与 Muse Code 提供，每百万输入 / 输出 token 分别为 4 / 20 美元（缓存输入 0.20）；Wonder Full 仅 Muse Code 订阅用户可用，不走 API。两者均将驱动 Muse agent，先给付费用户。
  • 主打 Active Memory（跨会话记住用户关键信息）与 Active Focus（遇阻换路径、重要动作前确认）；上下文 100 万 token；输入支持文本/图像/视频/音频，输出文本。
  • Artificial Analysis 独立评测：Wonder / Wonder Full（max）Intelligence Index 分别为 52 / 56（前代 Spark 1.3 max 为 48）；Wonder Full 在 Terminal-Bench 4.0 从 33% 升至 57%。幻觉率约 23%–27%，知识面（AA-Omniscience）仍弱于 Opus 5.5 等。是否开源未表态；完整安全报告「稍后」发布。
为什么重要

这是 Alexandr Wang 重组后 Meta 第一次以前沿模型正面竞争；第三方指数已跟上，但仍弱于 Opus 5.5（58）等顶档。【分析】

看点

完整安全报告；Wonder Full 是否开 API；开源承诺是否落地。

来源Meta · Artificial Analysis · TechCrunch · Axios

重点 · 2官方/一手

Anthropic：小模型或数月内能在物联网自我复制

  • 10 月 12 日 Anthropic 前沿红队（Zhou / Freeman）发文：实验显示，小型模型可能只需数月就能在商用物联网设备（智能烤箱、杂牌安卓电视盒等）上自我复制；复制体难关停（无中心关停点），倍增时间以天计。
  • 演示：15 台约 55 美元的安卓电视盒分布式跑 Gemma4-26B-A4B，约 0.39 token/秒。≤30B 模型已能完成复制链多数单步；9B 级模型在 9 类硬件中的 8 类上自行搭起推理服务。
  • 在防火墙隔离的 8 节点 GCP 模拟网（红roid，ADB 无认证）中，受测开源模型里仅 GLM-5.2 能可靠端到端复制：5 次试验中 4 次感染全部 8 节点、1 次 7/8。目标节点跑的是 Llama3.1-8B，控制模型在独立服务器上——测的是编排能力上限，不是野外爆发。
  • 按 Epoch Capabilities Index 趋势外推，年底前小模型或达 GLM-5.2 级复制能力。建议：ISP 流量异常监测、隔离通知、提高物联网默认安全。
为什么重要

把「AI 蠕虫」从理论推到可复现实验；入侵步骤被刻意简化，真实世界成功率更低，但 IoT 默认口令历史上本就极弱。【分析】

看点

年底前是否出现真正的小模型重量级复制体；厂商与 ISP 是否跟进默认安全。

来源Anthropic · The Verge

重点 · 3官方/一手

微软 Maia 300：2027 起多吉瓦推理部署

  • 10 月 12 日微软宣布：Maia 200 已在生产（Copilot 等），Maia 300 为第三代自研推理系统，面向长上下文、低延迟对话与多步 agent；自称每兆瓦 token 比领先 GPU 方案多约 40%，满配 96 加速器机架 token 吞吐约为 Maia 200 的 7 倍。
  • 单加速器：TSMC N2P 计算芯粒 + 8 栈 HBM4（288 GB、18 TB/s）、约 950 W TDP；机架 96 卡、167 kW、合计约 27.6 TB HBM。2027 年开始生产部署，目标成为微软产品与服务的主推理底座；未向 Azure 客户出租实例。
  • 效率对比未公布对照的具体 GPU、模型与服务配置，外部无法复测。
为什么重要

大厂把推理从租 GPU 转向自研硅片与整机共设计，直接影响 Copilot / Foundry 的单位成本与供给上限。

看点

2027 部署规模；是否对客户开放。

来源Microsoft · Microsoft Azure

实务观察

  1. 若在评估 Muse Wonder：先用自有长会话 / 编程任务对比 Opus 5.5 与 GPT-6 Sol，重点看记忆是否真能跨天复用、以及每任务成本（AA 测算 Wonder 约 4.52 美元/指数任务，高于 Sol）。
  2. 让 agent 触网或扫内网前，默认关闭无认证调试口（ADB 等），并对异常大流量出站做告警——Anthropic 实验的前提往往是「门没锁」。
