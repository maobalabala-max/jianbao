重点 · 1官方/一手媒体报道

Anthropic 也公布 Claude 的 ETH 否证

  • Anthropic 在 GitHub 公开论文与 Lean 4 形式化：确定性算法可在 2^O(n·loglogn/√logn) 时间内计数 3-SAT 的满足赋值，从而推出 ETH 不成立。说明称结果由内部研究版 Claude 发现，Lean 证明也由 AI 编写。
  • 据 WebProNews 汇总，Anthropic 论文称核心算法用约 1,400 万输出 token、无人类输入得到，并承认 OpenAI 的模型「独立且同时」得到类似结果；两家提交时间相隔约六小时。
  • 该界要到 100 亿变量以上才胜过穷举，作者明言「对实际求解没有意义」。仓库还写明：Lean 只检查证明，不检查形式化命题是否等于论文所说。
为什么重要

两家前沿实验室在同一天对同一难题给出各自证明，说明这类研究能力已不是单家独有。【分析】

看点

Williams 等人组织的公开核查会议，以及两份证明是否本质相同。

重点 · 2官方/一手

Anthropic：分析师在判断题上大多跟随 agent 的倾向

  • 50 名因果推断分析师用 Claude Code（Opus 4.8）完成约一小时的评估任务；agent 在每个开放选择上的倾向由抛硬币决定，分析师不知情。
  • 四个分析选择上平均 86% 跟随 agent 倾向（无影响时应约 50%）；已表态的人遇到 agent 反对，60% 改口。77% 事后复述了 agent 的论证，只有 15% 注明来源。
  • 局限：倾向是人为加强的，只测了一个任务、一个模型；不用 agent 的 11 人严重方法错误更多，但两组不可直接比较。
为什么重要

如果多个团队都在同一模型的偏好下做判断，表面上的「独立复现」可能并不独立，AI 安全研究同样如此。【分析】

来源Anthropic

重点 · 3官方/一手

谷歌 DeepMind 发布世界模型 Genie 4

  • 实时交互生成逼真世界，首次原生生成环境音、音乐与对话，可用自然语言随时改天气、镜头、角色；单段连贯时长约两分钟，是 Genie 3 的两倍。
  • Gemini 3.8 Flash 在循环中拆解目标、逐帧核对每步是否完成；演示中 Gemini 4 Argon 为机器人任务做计划，由 Genie 4 实时模拟。
  • 目前只向受信测试者开放研究预览，之后面向 Ultra 订阅用户和 Gemini API 早期伙伴。官方承认长时间运行后细节与物体会漂移。
为什么重要

世界模型正被当作 agent 和机器人的训练与测试场，模拟质量直接影响具身训练的成本。【分析】

来源Google DeepMind · TechCrunch

重点 · 4官方/一手媒体报道

甲骨文云引入谷歌 TPU、OpenAI Jalapeño 芯片

  • 甲骨文与英伟达宣布 OCI 扩到「数吉瓦级」Vera Rubin NVL72，并引入 Vera CPU；路透称这些系统部分改用甲骨文自研 Acceleron 网络芯片。
  • 甲骨文首次提供谷歌 TPU，CNBC 称这是谷歌芯片第一次跑在另一家超大规模云上；OpenAI 的 Jalapeño、Cerebras 与 SambaNova 也将上 OCI，上线时间与规模未披露。
  • 同日 OpenAI 与甲骨文宣布 Oracle AI Workspace 等四项产品，把甲骨文应用与数据接入 ChatGPT，尚未正式上线。
为什么重要

TPU 走出谷歌云、OpenAI 自研芯片进入第三方云，推理算力不再只有英伟达一条路。【分析】

实务观察

  1. 用 agent 做分析时，关键取舍先写下自己的选择和理由，再看 agent 的意见；需要独立复核的结论，换一个模型或让 agent 分别论证两边。
  2. 给任何开源或闭源模型配 shell 工具，默认封锁出网，并记录实际命令，不只看推理文本。
