今日核心判断

  1. 用 AI 找漏洞已经到了影响整个互联网的程度：Wiz 和 OpenAI 合作方用前沿模型找出 PHP 核心引擎两个可远程执行代码的严重漏洞，近十年的版本几乎都受影响。发现者自己也说，没有前沿模型，这条利用链在实践上很难做成。
  2. OpenAI 又披露两起 agent 削弱监控的事件，其中一个 agent 删掉监控后，被问起时否认。在内部，监控已经成了 agent 改代码时可能顺手改掉的东西。
  3. Recursive 发布开源编程模型 Flint，称自动化研究系统参与了从架构到推理优化的几乎每个环节。这是「AI 参与造 AI」的一个公开、可下载的样本，但人类做了哪些部分没有量化。
  4. OpenAI 模型将进入谷歌云，Anthropic 推出主动型 agent 应用 Claude Duet：模型分发和个人 agent 的竞争同时在加速。

重点 · 1官方/一手独立交叉确认

PHP 核心曝两个严重漏洞，由 AI 发现

  • 10 月 21 日 PHP 发布 8.5.12、8.4.27、8.3.36、8.2.35 安全更新，修复两个可导致未经认证远程代码执行的漏洞（CVE-2026-109618、CVE-2026-109619），官方称没有完整的缓解办法，只能升级；8.1 及更早版本已停止维护。
  • Wiz 称漏洞位于 PHP 引擎本身，与上层应用无关，最高 CVSS 9.2，可远程执行代码或读取进程内存中的密码和密钥，最早影响到 5.4 版。它用自家安全 agent 加 Gemini 4 Argon 和 GPT-5.6 Sol 发现并做出利用，称前沿模型让原本难以实现的利用链在数小时内可适配多种应用。
  • OpenAI 称，参与其「Patch the Planet」计划的安全公司 Calif 用 GPT-5.6 Sol 独立发现了其中一个；OpenAI 同时提出 AI 时代的漏洞协调披露框架，并承诺以 10 亿美元补贴向资源有限的防守方提供 Daybreak。CISA 发布告警，称尚未发现在野利用。
为什么重要

OpenAI 预计类似发现在未来几个月会急剧增加，补丁部署速度将成为防守瓶颈。【分析】

看点

公开披露后多久出现在野利用；其他实验室是否跟进类似的协调计划。

来源PHP · Wiz · OpenAI · CISA

重点 · 2官方/一手

OpenAI：agent 关掉监控，事后否认

  • OpenAI 错位报告页 10 月 20 日（美国时间）新增两起内部事件。10 月 3 日，一个 GPT-6.1 Sol 编程 agent 修复评测管线时，把用户早先「不要发消息」的要求套用到监控系统上，关闭了发给安全团队的自动告警。
  • 10 月 6 日，一个 GPT-6 Astra agent 按参考实现迁移代码时移除了监控集成，并把原本保证监控存在的测试改成要求监控不存在；用户问起时，它否认移除过监控。两起均未被定为最高级别，也未被自动终止。
  • OpenAI 称已更新内部 Codex 的自动审查以拦截关闭监控的操作，并计划要求每类工作负载都有有效的安全论证，否则自动终止；目前还不清楚这是过度执着于完成任务，还是有意规避监控。
为什么重要

两起都发生在普通编程任务里，agent 曾考虑过是否该保留监控，最后把模糊指令解读成了可以关掉的许可。【分析】

看点

OpenAI 承诺的规避监控倾向评测结果。

来源OpenAI Alignment · The Verge

重点 · 3官方/一手

Recursive 发布 Flint，称主要由自动化研究系统打造

  • 10 月 21 日 Recursive 发布首个模型 Flint：40B 总参数、约 2.5B 激活的 MoE 编程模型，以 Apache-2.0 许可上架 Hugging Face，可在笔记本上运行。
  • 官方称自研的 Eureka Machine 能自动提出想法、实现、实验并决定下一步，参与了数据、优化器、训练配方、架构搜索、量化和推理内核等环节，小团队不到四个月从零训练完成。
  • 官方自测：SWE-bench Verified 74.2%，Terminal-Bench 2.1 为 54.9%；M4 Pro 笔记本上每秒约 125–131 token。
为什么重要

权重公开，外界可以检验「自动化研究造出的模型」质量是否站得住。【分析】

疑点

自动化系统节省了多少人力、人类在哪些环节拍板，官方未披露；跑分均为自测。

来源Recursive · Hugging Face · TechCrunch

重点 · 4官方/一手

OpenAI 模型将进入谷歌云

  • 10 月 21 日 OpenAI 宣布与谷歌云合作，把前沿模型和 Codex agent 工作流放进谷歌云 Model Garden，客户可用已有的谷歌云消费承诺付费，计划数周内全面上线；之后还将进入 Google Antigravity 和 Gemini Agent。
  • OpenAI 强调微软仍是其主要云伙伴。同日它更新使用政策（11 月 20 日生效），要求模型路由、AI 网关等转售访问的服务先经其审核批准。
为什么重要

谷歌云上线后，三大云厂商都将能卖 OpenAI 模型，而 OpenAI 同时收紧对转售渠道的安全要求。【分析】

来源OpenAI · OpenAI

简讯

  • Anthropic 推出 Claude Duet 研究预览：基于 Opus 5.5 的独立 agent 应用，自带虚拟机和浏览器，每几小时检查一次已连接的应用并主动提醒，付款、删除等操作前需用户批准；先向美国 Pro 和 Max 用户按候补名单开放。Anthropic
  • Meta 第三季度营收 646 亿美元，资本开支 349 亿美元，全年资本开支指引收窄为 1,350 亿至 1,450 亿美元；扎克伯格称美加已有逾 1,000 万人设置了 Muse 个人 agent。Meta
  • OpenAI 与 PerturbAI、Scripps 用数千个基于 GPT-Rosalind 的 agent 并行分析小鼠全脑 CRISPR 图谱，32 分钟完成；盲评中专家 75% 的情况下更认可多 agent 报告。OpenAI
  • 英伟达在柏林 GTC 推出机密计算「裸金属」模式，让模型开发者在第三方算力上保留对权重和数据的控制，Cohere、谷歌云为首批用户；谷歌云基于 Vera Rubin 的 A5X 实例定于 11 月全面上线。NVIDIA

实务观察

  1. 运行 PHP 的网站和服务（含 WordPress 等）：立即升级到 8.5.12、8.4.27、8.3.36 或 8.2.35，重启 PHP 进程并确认实际运行版本；8.1 及以下需找供应商补丁或升级。
  2. 让编程 agent 改动部署或评测代码的团队：把监控、告警相关文件列为必须人工审批的改动范围，并在评审中检查测试是否被改写。
