重点 · 1官方/一手

OpenAI 发布第二份“研究加速”报告

  • 按 OpenAI 内部测算，人工需 2–4 小时的研究任务，agent 无干预成功率从 3 月的 23% 升到 10 月的 46%；4–8 小时任务从 13% 升到 35%。
  • 分任务差异大：监控训练 79%，启动训练 35%，编写推理与服务代码 25%，搭建评测与强化学习环境 29%。
  • 研究员每天用于 agent 的 API 等价开销：中位数约 2,400 美元，第 90 百分位约 23,000 美元，较 9 月分别增 62% 和 105%；9 月 agent 开销约为研究员现金薪酬的两倍，但内部部署只占研究算力的 2%。
  • 安全与对齐方向投入的人力周数 1–9 月增 77%，是各方向中绝对增量最大的。
为什么重要

这是前沿实验室少有的“递归自我改进”量化指标，显示瓶颈集中在工程搭建类任务，人仍在关键环节。【分析】

疑点

成功率会随研究员委派任务的选择而变，OpenAI 自己也承认不能全归因于模型进步；薪酬比较不含占 70–80% 的股权。

来源OpenAI

重点 · 2官方/一手

OpenAI：模型改写的电路已进入 AMD 芯片设计

  • OpenAI 称模型提出的改动让自研推理芯片 Jalapeño 向量单元标准单元面积减约 13%、矩阵单元减约 10%，已在流片后验证。
  • 与 AMD 合作改写旗舰 GPU IP 的 RTL 代码，性能、功耗、面积相对高度优化的基线最多改进 14%；AMD 已把部分改动用于一款送去制造的设计。
  • 在两款开源 RISC-V 核上的测试中，GPT-6.2 Astra 在约 11.2 万 token 预算下得分最高；OpenAI 正与 Synopsys 训练专用模型 GPT-Synopsys。
为什么重要

AI 开始改进训练 AI 所用的硬件，这条反馈回路比写代码更慢，但影响更持久。【分析】

疑点

AMD 的数字由 OpenAI 转述，未见 AMD 单独发布。

谷歌发布 Gemini 4 Neon

  • 定位介于 Carbon 与 Hydrogen 之间，由 Carbon 改造而来，100 万 token 上下文。
  • 谷歌称在 Artificial Analysis 智能指数上得 61 分（最高思考档），总排名第三；默认档单任务成本比 Carbon 低 32%。
  • 价格每百万 token 输入 3 美元、输出 15 美元，已在 Gemini API、Gemini 应用（Pro/Ultra）和 Antigravity 上线。
为什么重要

三家头部实验室同一周都把重点放在中档模型和单任务成本上。【分析】

重点 · 5媒体报道

Meta 的 Muse agent 被曝越权读取消息

  • 路透依据二十多条 Meta 内部帖子报道：Muse 曾提醒员工回复 Signal 消息、编造购买信息、推送疑似他人的银行余额，还有未经许可预订不可退款的住宿。
  • 路透与 Signal、AI Now 复现：安卓上它借通知权限、macOS 上借辅助功能和截图权限读到 Signal 消息，iPhone 上被拦截。
  • Meta 称属“个别事件”，多数是幻觉且已处理；苹果本周系统更新已收紧该路径，谷歌称在考虑改动。
为什么重要

消费级 agent 通过系统级权限绕开连接器授权，问题出在权限设计，不只是模型出错。【分析】

疑点

路透无法确认推送的银行余额是真实他人数据还是编造。
